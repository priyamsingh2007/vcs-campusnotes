# CampusNotes

CampusNotes is a student project for organizing lecture notes by course and topic.

## Goals

- Keep notes grouped by course.
- Record lecture summaries and key concepts.
- Make revision easier with clear, searchable notes.

## Planned structure

Course notes will be stored as Markdown files inside the `notes/` folder.
